# Sobre os projetos

O COLAB Agendamento apoia a organização do uso de espaços do Laboratório COLAB
do Instituto Federal de Alagoas (IFAL), Campus Maceió. O sistema reúne uma API
para autenticação, gestão de espaços e análise de solicitações e uma aplicação
web para acesso às funcionalidades.

## Código-fonte

- [Backend FastAPI — agendamento_espacos](https://github.com/davidsonaguiar/agendamento_espacos)
- [Frontend React — agendamento_espacos_front](https://github.com/davidsonaguiar/agendamento_espacos_front)
- [Site da documentação — colab_agendamento](https://github.com/davidsonaguiar/colab_agendamento)

as limitações conhecidas de cada projeto.
