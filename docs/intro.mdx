# COLAB Agendamento

O **COLAB Agendamento** reúne os projetos que apoiam a gestão dos espaços do
Laboratório COLAB do Instituto Federal de Alagoas (IFAL), Campus Maceió. O
backend centraliza usuários, espaços, projetos, solicitações e reservas. O
frontend oferece a interface web para acesso ao sistema e consulta dos
laboratórios.

![Tela de acesso do frontend do COLAB Agendamento em um monitor de mesa](/img/login-1366.png)

## O que você encontra aqui

- No [guia de laboratórios e solicitações](./guia-do-usuario/fluxo-de-agendamento.mdx),
  conheça as telas, os papéis e o fluxo de pedido de uso.
- Em [conta e acesso](./guia-do-usuario/conta-e-acesso.mdx), veja como funcionam
  cadastro, autenticação e recuperação de senha.
- Para entender os componentes e seus limites, consulte
  [arquitetura e integração](./desenvolvimento/arquitetura-integracao.mdx).
- Siga as instruções de [execução local](./desenvolvimento/execucao-local.mdx)
  para preparar os projetos no ambiente de desenvolvimento.

:::note[Escopo e estado]
Esta documentação descreve o código disponível nos repositórios consultados.
Algumas telas do frontend usam dados demonstrativos; elas não significam que
cada operação esteja integrada à API. As funcionalidades futuras são
identificadas como tais.
:::
