# Sistema de Biblioteca

O **Sistema de Biblioteca** controla o acervo, os empréstimos e as
devoluções de livros de uma biblioteca escolar.

## Para quem é esta documentação

- **Usuários:** consulte o [Guia do Usuário](./guia-do-usuario/instalacao.mdx).
- **Desenvolvedores:** consulte o [repositório do projeto](https://github.com/davidsonaguiar/colab_agendamento).
